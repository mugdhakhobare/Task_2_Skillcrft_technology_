# Customer Segmentation using K-Means Clustering

This project uses the K-Means Clustering algorithm to group retail store customers based on their annual income and spending score. Python libraries such as Pandas, Matplotlib, and Scikit-learn were used for data preprocessing, clustering, and visualization. The Elbow Method was used to find the optimal number of clusters. The final output visualizes different customer groups and their centroids. This project helped in understanding unsupervised machine learning and customer segmentation techniques.
